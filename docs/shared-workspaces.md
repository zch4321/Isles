# 附加共享工作区

日期：2026-10-28。

## 使用方式

侧栏“共享工作目录”管理全局列表，群聊详情管理群列表，创建或编辑 Agent 管理个人附加列表。路径指向 Isles 服务所在机器上的现有目录，支持多个项目和带空格、中文的路径。多个 Agent 指向同一路径时操作同一份文件。

| 操作                       | Agent 目录的变化                      |
| -------------------------- | ------------------------------------- |
| 新建 Agent                 | 合并个人填写的目录和当前全局列表      |
| 创建群或邀请成员           | 向加入的成员追加群当前列表            |
| 全局新增路径               | 追加给所有现有 Agent                  |
| 群新增路径                 | 追加给当前群成员                      |
| 移除共享配置、退群、删除群 | 保留 Agent 已保存的路径               |
| 编辑 Agent 路径            | 按用户保存的列表更新                  |
| 原样保存共享列表           | 保留 Agent 的个人编辑结果             |
| 修改共享路径               | 分发新路径，保留 Agent 已收到的旧路径 |

目录以真实绝对路径去重，Windows 按大小写不敏感方式比较。个人主目录保存 Isles 规则、配置和临时文件，外部目录保存项目文件。内置的 `<workspace-root>/shared` 继续供所有 Agent 使用。

## 生效与运行

各连接使用建立时的目录快照。主代理或后台子代理仍有活动时，目录修改等待全部活动结束，后续消息的自动投递排队；随后恢复原 session 并应用新列表。MCP 主动收信继续可用。停止的 Agent 保持停止，在恢复时加载目录。

群消息带 `workspace_paths` 头部，`list_channels` 返回当前群目录，Agent 的工作说明列出其个人附加目录。Agent 执行项目命令时指定对应目录并读取项目自己的规则。所有目录配置均保留原位置的文件。

## 实现

- Agent 和群分别持久化 JSON 目录数组，使用当前数据库 baseline。
- 全局目录保存为 TOML `[paths].shared_workspaces`；`GET/PUT /api/workspaces` 提供界面查询和保存。界面保存时分发新增路径；手动修改 TOML 并重启后作为新建 Agent 的默认列表。
- 创建群、入群和群目录新增与成员路径更新在同一存储事务提交。全局写入复用配置串行队列，Runtime 顺序应用新增目录。
- 服务校验现有目录并解析真实路径，保存时完成去重。目录失效时提示具体路径，用户可修复目录或在设置中移除。
- Codex 更新 thread 与 turn 的可写目录；Claude 使用 `--add-dir`；Kimi 逐条调用 workspace `add-dir`；OpenCode 设置对应目录的原生规则；DSH 同时扩展文件与命令沙盒。通用 ACP 使用其额外目录能力。
- OpenCode 默认权限的目录名使用原生规则可准确表示的字符；含 `*`、`?`，以及 Unix 文件名中的字面反斜线时，界面提示重命名或移除该路径。

## 验证

覆盖路径校验、真实路径别名去重、配置持久化、自动追加与保留、原样保存、批量创建、固定会话恢复、后台活动等待、初始化期间修改和消息中的项目路径。浏览器覆盖全局、Agent、群组设置以及桌面和移动布局。

DSH 在本机真实 Windows 沙盒中验证多个额外目录，覆盖带空格路径、目录外访问、链接解析和多个 ACL 授权的释放。

`pnpm check` 通过格式、ESLint、全工作区类型检查、生产构建及 619 项测试；1 项 Unix 特有文件名测试在 Windows 跳过。验证时指定真实 Codex 协议生成程序与 DSH 原生 carrier。
