- 使用独立测试目录、后端端口 `54320` 和 Web 端口 `55174`，不使用用户的原生会话作为测试对象。
- 管理 Web/HTTP 不做登录鉴权，只监听本机；对象 MCP 使用独立 token 并检查私聊归属。
- 本轮交付 Codex 对象、固定 thread、私聊、执行详情、排队、停止/恢复与原生问题回答入口。

## 5. 验收中修复的问题

- 空 thread 未落盘：首次创建后经原生 `thread/inject_items` 注入已有启动规则，不调用模型，不新建替代 thread。
- 原生默认开启子 agent：对象配置显式关闭两个委派 feature，保留固定 session 约束。
- SSE 重放：处理断开与背压，分页游标只指向实际返回的事件，避免漏读或结束后继续写响应。
- 正常关闭时的活动执行：与异常退出一致保留“待核对”状态，显式恢复后再处理后续队列。
- 重复服务启动：在读取和恢复业务状态前获取数据目录占用锁，避免破坏正在执行的状态。
- Fastify 日志控制配置与浏览器测试共享数据竞态已修正。
